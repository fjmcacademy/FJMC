# FJMC Academy Smart OMR — Starter Package

Yeh ek **standalone starter application** hai. Existing FJMC Academy website/Firebase files ko change nahi karta.

## Features in this starter
- Login with admin/teacher roles (SQLite-backed)
- Dynamic exam question count (1–300)
- Answer key and correct/wrong/blank marking rules
- Printable A4 OMR PDF template with roll-number bubbles and handwritten-name field
- Mobile camera image upload (HTTPS deployment par camera capture available)
- Bulk JPG/PNG/WebP upload; physical scanner se export ki hui images bhi upload ho sakti hain
- Baseline bubble recognition for this package's own template
- Unclear answer review and manual correction
- Ranking, CSV, Excel and PDF results exports
- Password hashing, role checks, upload size limit and basic audit log

## Important accuracy limitation
The included recognizer uses fixed coordinates and expects the generated sheet to be photographed/scanned as a full A4 page with minimal skew. This is a **starter/calibration baseline, not yet a validated production OMR engine**. Test with your actual printer, phone and scanner. For angled mobile photos, mixed templates, multipage answer sheets, or high-stakes results, add perspective correction / registration-mark alignment and run a calibration test set. Flagged answers must be reviewed. Handwritten names are not automatically OCR'd; they are entered by the reviewer.

## Windows local setup
1. Install Python 3.11 or 3.12 from python.org and tick **Add Python to PATH**.
2. Extract this ZIP to a folder, e.g. `C:\FJMC-Smart-OMR`.
3. Open Command Prompt in that folder.
4. Create virtual environment:
   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   ```
5. Install dependencies:
   ```bat
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
6. Set a permanent secret and first admin password before the first run:
   ```bat
   set OMR_SECRET_KEY=replace-with-a-long-random-secret
   set OMR_ADMIN_USER=admin
   set OMR_ADMIN_PASSWORD=ChangeThisToALongUniquePassword123!
   python app.py
   ```
   **Keep credentials private.** The first account is created only if the database has no users. If you omit `OMR_ADMIN_PASSWORD`, a random initial password is printed in the server console.
7. Open `http://127.0.0.1:5000`.
8. Create an exam, download its OMR PDF, print at **100% / actual size**, then test with a few sample sheets.

## Phone camera
For local testing you can upload an existing photo. Browser camera capture and reliable mobile camera permissions generally require HTTPS. When deployed, use HTTPS and a trusted domain.

## Physical OMR/document scanner
Use the scanner's software to scan at 300 DPI, grayscale or black-and-white, save each page as JPG/PNG, and bulk upload. Direct machine control is not included because it depends on scanner make/model, drivers, and OS.

## Deployment notes
This app needs a Python host (not plain static GitHub Pages). Use a host that supports Python/Flask, persistent disk or managed database, HTTPS, environment variables, backups, and logs. Example production command:
```bash
gunicorn --workers 2 --bind 0.0.0.0:$PORT app:app
```
Set environment variables in the host dashboard:
- `OMR_SECRET_KEY`: strong random secret, never commit it
- `OMR_ADMIN_USER`: initial admin username
- `OMR_ADMIN_PASSWORD`: initial admin password (12+ chars)
- `HTTPS_ONLY=1` when behind HTTPS proxy correctly configured
- `OMR_DB_PATH`: persistent disk path if needed

Do not deploy with Flask's development server. Before real exams, add CSRF protection, rate limiting, email/password reset, database backups, upload malware scanning, retention policies, and full template alignment/calibration. Restrict uploaded files and access to result exports. Review your hosting provider's data location/privacy terms.

## OMR sheet use
- Use the PDF generated by this application for the scanner's expected bubble layout.
- Roll number supports up to 8 digits in the template.
- Handwritten name field is not OCR-read.
- A 1-page template is laid out for up to 105 answers; larger question counts produce continuation pages. This starter's fixed-coordinate reader does **not yet automatically stitch/read continuation pages**; those answers will be flagged/blank for review. Use <=105 questions per scan until multipage alignment is implemented.
- If the camera crops or tilts the sheet, readings may be wrong. Always verify flags and a sample of unflagged sheets before publishing.
