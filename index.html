CONFIGURATION

Data & Setup

Local data and backup

Current version stores exams and results in this browser's local storage. It does not sync between phones or computers.

Before production use

  • Add secure login and roles.
  • Use Firebase or another backend with access rules for shared data.
  • Validate the automatic OMR reader with actual printed sheets and scanner samples.
  • PDF parsing/OCR and direct USB machine control require additional components.

Privacy: use sample data only on shared/public computers.
