How answer reading works

The uploaded photo is currently a reference image only. Bubble recognition needs calibrated image processing for this exact printed layout and camera angle. This build preserves answers you already selected when you reopen the review for the same paper, instead of resetting them to blank.

Machine compatibility

This web app can import scanner-exported images and CSV response files. Direct USB/serial control and proprietary scanner formats require the exact manufacturer/model, driver and output specification.

CONFIGURATION

Setup & deployment

Firebase configuration (optional for prototype)

This downloadable starter stores data in browser localStorage. To share papers/results between admins and devices, create a Firebase project, enable Authentication, Firestore and Storage, then connect a backend-enabled version with security rules.

Never place service-account private keys in frontend JavaScript.

Privacy note

Do not upload real student records to a shared or public device while using local prototype storage. Use authenticated access and restrictive Firestore/Storage rules before production.
