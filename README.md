# FJMC Academy Smart OMR — GitHub Pages

1. Create a **separate repository** such as `fjmc-smart-omr` so the current FJMC website is untouched.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for the published URL shown on the Pages page.

Included: responsive interface, 20/30/50/75/100 questions, answer key, correct/negative marks, printable sheet, response entry, score calculation and CSV download.

Limitations: photo upload is only a preview; bubbles are not automatically detected. No shared database, secure login, batch scanning or leaderboard. This is a static starter, not a production exam scanner. Browser local storage is device-specific. For automatic scanning, add and test JavaScript image-processing and perspective correction separately.
