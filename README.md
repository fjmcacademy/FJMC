# FJMC OMR Scanner (starter implementation)

Separate project; does not modify your existing FJMC Academy website.

## Features
- Create a paper with 25–200 questions and an answer key (A–D).
- Generate a matching printable A4 OMR sheet PDF.
- Scan a photo/image or a scanned PDF; camera capture works on HTTPS or localhost.
- Calculate correct/wrong/blank and marks with optional negative marking.
- Download result CSV.
- The scanner is designed for the OMR template generated by this app. It is not a universal reader for arbitrary OMR layouts or handwritten answers.

## Run locally
Requires Python 3.10+.

```bash
cd backend
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
Open http://127.0.0.1:8000

For phone camera access over a network, deploy with HTTPS. Camera permission is blocked on ordinary HTTP except localhost.

## How to use
1. Set exam name, number of questions, answer key, marks and negative marks.
2. Click **Save paper & download blank OMR**. Print at 100% scale on A4.
3. Students fill bubbles completely using a dark pen/pencil.
4. Scan the generated sheet only. Upload JPG/PNG or a PDF made from scans, or use **Use camera**.
5. Review low-confidence/multiple-mark answers before relying on the score.

## Important
- This is a functional starter for a controlled, matching sheet layout. Camera angle, shadows, poor printing and marks outside bubbles can reduce accuracy.
- The initial reader assumes the sheet is photographed/scanned nearly upright and fills most of the frame. Production use should add four-corner perspective correction, sheet-ID/roll-number decoding, batch queue, user authentication, audit logs and human review.
- Do not use results as final for high-stakes exams without validating on representative sheets.
