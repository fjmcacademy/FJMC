# FJMC OMR Scanner

Separate project; this app does not modify the existing FJMC Academy website.

## Added in this version
- Generated A4 OMR template includes an 8-digit roll-number grid (digits 0–9 down each of 8 columns).
- Batch scan: select multiple image files and/or PDF files. Each PDF page is treated as one sheet. Maximum 1000 sheets and 100 MB combined upload per batch.
- Saves each processed sheet as a JPG audit image and creates a question-wise result PDF in `data/students/<roll-number>/<timestamp>/` (unreadable roll numbers go under `UNREADABLE`). Duplicate roll numbers are saved as separate timestamped attempts rather than overwriting.
- Saved results endpoint and all-students CSV/PDF exports.
- Dense ranking: scores 95, 95, 92, 89, 89 produce ranks 1, 1, 2, 3, 3.
- Existing CSS is preserved.

## Run locally
Requires Python 3.10+.

```bash
cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
Open http://127.0.0.1:8000

## How to use
1. Set exam name, question count (25–200), answer key, marks and negative marks.
2. Click **Save paper & download blank OMR PDF**. Print at 100% scale. Do not resize or crop it.
3. Each student fills one bubble in each of the 8 roll-number columns. In each column, fill the row for that digit. For roll number `00000123`, fill digit 0 in columns 1–5, then 1, 2, 3 in columns 6–8.
4. Upload one or more photos or PDF scans; a PDF can contain up to 1000 pages. A clear, upright, full-page scan works best.
5. Review rows where roll number is unreadable or answer detection flags blanks/multiple marks. Validate the scanner on representative sheets before official use.
6. Use **Load saved results**, **Export all results CSV**, or **Download all-results PDF** to retrieve stored results.

## Storage and deployment
By default, files and result records are saved in `backend/data` (the app's project-level `data` directory). To choose another storage path, set environment variable `OMR_DATA_DIR` to a writable persistent directory. On Render, configure a persistent disk and set `OMR_DATA_DIR` to its mount path, for example `/var/data/fjmc-omr`. Without a persistent disk or external storage, data saved to an ephemeral container filesystem may be lost on redeploy/restart. Back up the data directory regularly.

## Accuracy limitations
This scanner is calibrated for the OMR template generated by this app; it is not a universal reader for arbitrary OMR designs. Bubble reading uses image darkness thresholds and may be affected by shadows, skew, low resolution, photocopying, marks outside bubbles, or scans that are cropped. The roll-number detector requires exactly one clearly filled bubble per digit column. Unreadable numbers are saved for manual review; do not rely on unreviewed output for high-stakes exams. Perspective correction, review/edit controls, authentication, access control, and transactional database storage should be added before production use with sensitive student data.
